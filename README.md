# Demo

This is a sample project demonstrating basic functionality.

## Features
- Feature 1: Basic setup and initialization
- Feature 2: Configuration management
- Feature 3: Testing
- Feature 4: Documentation

## Usage
Clone and install dependencies to get started.

## Sample Test Operations
- Go to the app folder: `cd angular-login && npm install`
- Run unit tests (Karma): `npm test`
- Build the project: `npm run build`
- Serve locally and verify at `http://localhost:4200`: `npm start`
- Run tests once without watch mode: `npm test -- --watch=false`
- Run tests in headless Chrome: `npm test -- --browsers=ChromeHeadless`
- Build for production: `npm run build -- --configuration production`
- Find the build output in the `dist/` folder
